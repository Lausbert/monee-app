## Одноэкранное резюме

**Кому подходит:** если вам нужно организовать похороны и вы хотите удержать расходы под контролем, даже когда нет сил разбираться в деталях.  
**Какое решение поддерживает:** *какой формат выбрать* и *сколько закладывать на каждую часть*, чтобы не всплывали «неожиданные» счета.  
**Как пользоваться:** пройдите по схеме ниже, затем заполните печатный чек‑лист: сначала обязательное, потом «важно для семьи», и только затем — дополнительные элементы.

---

## С чего начать: три рамки, которые снижают хаос

1) **Определите формат**: кремация или захоронение. Это одно из решений, которое сильнее всего меняет структуру расходов.  
2) **Выберите уровень простоты**:
- *минимальный*: без сложной церемонии, максимум — прощание и базовые услуги;
- *сдержанный*: короткая церемония + несколько дополнительных пунктов;
- *расширенный*: больше времени, больше участников, больше «элементов события».

3) **Зафиксируйте предел**: не сумма «в голове», а правило. Например:  
- «Если пункт не несёт смысла для семьи — не берём».  
- «Если добавка увеличивает общий план больше чем на 10% — пауза и перепроверка».

## Быстрый поток решений (мини‑схема)

```
Старт
  |
  v
Кремация? ---- да ----> Урна + крематорий + место хранения/захоронения праха
  | нет
  v
Захоронение -> участок/место + копка/закрытие + плита/крест (сроки/правила)
  |
  v
Нужна церемония в зале/храме?
  | да -> аренда/служба + ведущий/служитель + музыка/звук (по желанию)
  | нет -> короткое прощание (минимальный набор)
  |
  v
Сколько гостей?
  | мало -> транспорт базовый
  | много -> транспорт/координация/время персонала растут
  |
  v
Дополнения (цветы/поминальный стол/печать/стриминг) -> только после обязательного
```

## Категории расходов: что обязательно, а что — опционально

Ниже — удобная логика: **сначала “ядро”**, затем **“место и процесс”**, потом **“церемония”**, и только потом **“дополнения”**.

### 1) Ядро (обычно 50–70% плана)
Это то, без чего процесс просто не состоится:
- услуги ритуальной службы (оформление, организация, персонал);
- подготовка и хранение (если требуется по правилам/времени);
- базовые принадлежности (гроб/урна, минимум по выбранному формату).

**Правило контроля:** если «ядро» уже близко к верхней границе (70%), любые дополнения должны быть очень осознанными.

### 2) Формат: кремация или захоронение (обычно 15–35%)
**Кремация** чаще даёт больше гибкости по месту и срокам, но может добавлять отдельные позиции (урна, ниша, церемония при крематории).  
**Захоронение** обычно включает больше операций “на месте” (участок/место, работы, требования к памятному знаку и срокам).

**Пороговое правило:** если вы не уверены в решении, оцените оба варианта в одной таблице и сравните не суммы, а **количество обязательных пунктов** — где их меньше, там проще удержать бюджет.

### 3) Церемония и прощание (обычно 5–20%)
- аренда зала/помещения;
- услуги ведущего/служителя (если нужно);
- звук/музыка/экран (если важно семье).

**Правило смысла:** оставьте 1–2 элемента, которые реально помогают попрощаться (например, короткая речь и музыка), и уберите всё, что «просто принято».

### 4) Транспорт и логистика (обычно 5–15%)
- катафалк/перевозка;
- транспорт для близких (если нужно);
- дополнительные часы персонала, если план “растягивается”.

**Простое “если‑то”:**
- если гостей больше, чем помещается в 2–3 машинах → транспорт становится отдельной статьёй;
- если локаций больше двух (дом/зал/кладбище) → логистика почти всегда дорожает.

### 5) Документы, сборы, мелкие обязательные платежи (обычно 3–10%)
Это та зона, где чаще всего «вылезают» неожиданности:
- регистрационные действия, справки, разрешения (по местным правилам);
- сборы площадки/кладбища/крематория;
- срочность (если сроки сжатые).

**Правило резерва:** держите отдельный “буфер” 5–10% именно под такие вещи — не под цветы.

### 6) Дополнения (0–20%, по вашему выбору)
- цветы, венки, оформление;
- печатные материалы;
- фото/видео/онлайн‑трансляция;
- поминальный стол.

**Стоп‑правило:** дополнения выбираются только после того, как закрыты пункты 1–5 и понятен общий предел.

## Печатный “лист решений” (одна страница)

Распечатайте и заполняйте по мере звонков/согласований — так вы не будете пересобирать картину каждый раз.

**Чек‑лист сметы (заполнить):**

- Формат: ☐ кремация ☐ захоронение  
- Уровень простоты: ☐ минимальный ☐ сдержанный ☐ расширенный  
- Предел: ____________ (в вашей валюте)  
- Буфер на документы/сборы: ☐ 5% ☐ 10%

| Статья | Нужно? | Описание выбора | Оценка | Подтверждено (да/нет) |
|---|---|---|---|---|
| Ядро: организация/персонал | ☐ | | | |
| Подготовка/хранение | ☐ | | | |
| Гроб или урна | ☐ | | | |
| Крематорий / работы на месте | ☐ | | | |
| Место: участок/ниша/хранение праха | ☐ | | | |
| Церемония: зал/служба | ☐ | | | |

## Quick recap (чек‑лист)

- ☐ Сначала выбрал(а) формат: кремация или захоронение  
- ☐ Зафиксировал(а) уровень простоты и предел  
- ☐ Закрыл(а) “ядро” и логистику до любых дополнений  
- ☐ Выделил(а) буфер 5–10% на документы и сборы  
- ☐ Все пункты записаны в одну таблицу и подтверждены отдельно
