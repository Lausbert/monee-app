- Para quem isto é útil: Lares partilhados onde pelo menos uma pessoa trabalha de casa; casais, companheiros de casa ou famílias que querem manter os custos de serviços justos e o clima tranquilo.

## A Ideia Central: Dividir o que é Partilhado, Ponderar o que é Usado

Os serviços não são todos iguais. Algumas partes são essencialmente fixas (a ligação e velocidades base), outras variam com o uso (aquecimento em dias frios, longas chamadas, luzes, eletrodomésticos). Quando uma pessoa trabalha de casa, as suas “horas em casa” podem impulsionar parte desse uso variável. Uma divisão justa:

- Mantém as partes fixas partilhadas por igual.
- Pondera as partes variáveis por quanto cada pessoa provavelmente usa.
- Adiciona sobretaxas específicas apenas quando há um fator claro (escritório dedicado, equipamento de alto consumo, internet premium para trabalho).

Mantenha previsível, fácil de seguir e aberto a pequenos ajustes em vez de renegociação constante.

```
START
  |
  |-- Do you have separate meters or itemized sub-bills by room/device?
  |       |-- Yes --> Pay what you use + split any fixed fees equally. END
  |       '-- No --> continue
  |
  |-- Does one person’s home time exceed others by ~50% or more?
  |       |-- Yes --> Use Time-Weighted Split for variable utilities.
  |       '-- No --> continue
  |
  |-- Is there a dedicated home office (separate room/space)?
  |       |-- Yes --> Equal Base + Office Surcharge (electricity/heating if applicable).
  |       '-- No --> continue
  |
  |-- Is work the main reason for higher internet speed/reliability?
  |       |-- Yes --> Equal Base + WFH Internet Uplift for the worker.
  |       '-- No --> continue
  |
  '-- Default --> Fixed-Variable Split: Fixed equally; variable by simple weighting.
END
```

Notas:
- “Variável” = dependente do uso (eletricidade, aquecimento, água).
- “Fixa” = acesso/ligação e funcionalidades que não mudam com o uso (a maioria dos planos de internet).

## Quatro Métodos Práticos (Escolha um ou Combine de Forma Leve)

1) Divisão Fixo‑Variável (padrão)
- Como funciona:
  - Considere uma parte razoável de cada serviço como fixa; divida-a igualmente.
  - Considere o restante como variável; divida por uma ponderação simples, como a quota de horas em casa.
- Quando funciona melhor: Quer uma regra simples que abranja todos os serviços sem comparar fatura a fatura.
- Vantagens: Simples, consistente, escalável para mais de duas pessoas.
- Desvantagens: Requer acordo sobre a suposição de fixo/variável.
- Dica: A internet é maioritariamente fixa; eletricidade/aquecimento/água têm partes realmente variáveis.

2) Divisão Ponderada pelo Tempo (quando as horas em casa diferem muito)
- Como funciona:
  - Divida os serviços variáveis pela quota de “horas em casa” de cada pessoa durante períodos típicos de trabalho.
  - Mantenha as partes fixas iguais.
- Quando funciona melhor: Uma pessoa fica muito mais tempo em casa durante o dia, e isso claramente impulsiona o uso.
- Vantagens: Transparente, matemática simples; reflete a realidade do trabalho de casa.
- Desvantagens: Pode parecer granular demais se os horários oscilam com frequência.
- Salvaguarda: Limite os resultados para permanecer dentro de uma faixa confortável (por exemplo, ninguém paga menos de 0,8× nem mais de 1,5× da divisão igual) para evitar casos extremos.

3) Sobretaxa de Escritório/Dispositivo (quando um espaço ou dispositivo aumenta o uso)
- Como funciona:
  - Mantenha a divisão base igual.
  - Adicione uma sobretaxa clara para um escritório dedicado (aquecimento/arrefecimento/iluminação) ou equipamento de alto consumo (workstation desktop, servidores, iluminação extensa).
- Quando funciona melhor: Uma divisão específica ou dispositivo é o motor óbvio do consumo extra.
- Vantagens: Aponta a causa real; evita suposições amplas.
- Desvantagens: Requer acordo sobre um valor de sobretaxa justo; evite “cobrar tostões” por itens pequenos.

4) Acréscimo de Internet (quando o trabalho dita o plano)
- Como funciona:
  - Divida o plano base igualmente.
  - Se o trabalho exigir velocidade superior ou funcionalidades de nível empresarial, adicione um acréscimo modesto para a pessoa que trabalha de casa.
- Quando funciona melhor: O plano seria mais barato sem a exigência do trabalho de casa.
- Vantagens: Mantém a internet previsível e evita discutir o uso diário.
- Desvantagens: Requer uma visão partilhada do que conta como “exigido pelo trabalho”.

Pode misturar de forma leve. Exemplo: Divisão Fixo‑Variável para eletricidade e aquecimento; Acréscimo de Internet para a banda larga.

## Estimar Fixo vs Variável (Sem Complicar)

- Eletricidade: Misto. Iluminação e eletrodomésticos base são semi‑fixos; uso de workstation durante o dia é variável.
- Aquecimento/Arrefecimento: Largamente variável; ocupação diurna aumenta o tempo de funcionamento.
- Água: Variável; mais tempo em casa implica maior uso durante o dia.
- Internet: Maioritariamente fixa; picos de uso raramente alteram a fatura, a menos que o plano em si seja atualizado.

Se quiser um ponto de referência: compare uma fatura de baixo uso com uma de alto uso. A parte estável parece fixa; a parte que muda é variável. Não precisa de precisão perfeita—o acordo importa mais do que a exatidão.

## Defina Salvaguardas para Manter o Conforto

Qualquer que seja o método escolhido, concordem com dois limites:

- Regra de simplicidade: Um método principal para todas as faturas, mais no máximo uma sobretaxa direcionada se claramente justificada.
- Limite de resultado: Mantenha a quota de cada pessoa dentro de uma faixa justa em torno do igual (por exemplo, 0,8×–1,5× da divisão igual). Isto evita picos estranhos quando as suposições falham.

## Exemplos (Sem Valores Monetários)

- Eletricidade Ponderada pelo Tempo:
  - Duas pessoas. Uma fica em casa aproximadamente o dobro de horas nos dias úteis.
  - Divida a eletricidade em base igual mais variável por quotas de horas em casa, depois aplique o limite de resultado se necessário.

- Sobretaxa de Escritório para Aquecimento:
  - Uma pessoa usa uma pequena divisão dedicada durante o trabalho.
  - Mantenha o aquecimento igual para espaços partilhados; adicione uma sobretaxa modesta para o escritório durante o período de aquecimento.

- Acréscimo de Internet:
  - Plano escolhido principalmente para chamadas e uploads remotos de trabalho.
  - Divida o plano igualmente; adicione um pequeno acréscimo pelo benefício de trabalhar de casa.

Estes exemplos ilustram padrões, não percentagens fixas. O objetivo é conforto e clareza mútuos.

## Dicas Finais para Reduzir Atrito

- Dê um nome à regra uma vez e siga-a: Um método claro e consistente supera recálculos intermináveis.
- Mantenha as sobretaxas específicas e poucas: Só quando uma divisão ou dispositivo aumenta claramente o uso.
- Anote o limite e o ponto de revisão: Mantém expectativas alinhadas e o stress baixo.
- Registe entradas partilhadas onde já acompanha despesas: Um único local para notas evita confusão mais tarde. O Monee suporta lares partilhados, categorias e notas simples se precisar.

Escolha um método, concorde nas salvaguardas e deixe a folha de trabalho fazer o trabalho pesado. O objetivo não é precisão perfeita—é uma divisão justa que todos entendem e com a qual se sentem confortáveis.
