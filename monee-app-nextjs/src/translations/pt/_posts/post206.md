Decidir **quanto gastar em estacionamento e portagens por semana** ajuda a reduzir surpresas, manter consistência e escolher rotas e hábitos sem culpa. Este guia ajuda-o a **criar um teto semanal realista** e a escolher entre opções (rotas, passes, estacionamento, hábitos) com clareza — sem procurar a “solução perfeita”.

## Aquecimento de valores (3 prompts rápidos)

Antes de mexer em números, responda (em 30 segundos):

1. O que pesa mais nesta fase: **poupar**, **tempo** ou **menos stress**?
2. O que é “aceitável” para si numa semana difícil: **mais custo**, **mais tempo**, ou **mais planeamento**?
3. Que valor quer proteger: **tranquilidade**, **autonomia**, **previsibilidade**, **aprendizagem**?

Decisões são sobre **ajuste**, não perfeição.

## O que significa “teto semanal” (e por que funciona)

Um teto semanal é um limite simples: “Nesta semana, eu gasto **até X** em estacionamento + portagens.”  
Não é punição. É um **guia** para escolher, em cada dia, a opção mais alinhada com o que importa.

Funciona porque:
- agrupa decisões pequenas num **limite único**
- ajuda a evitar “só hoje…” repetido
- cria espaço para aprender e ajustar sem dramatizar

## Passo 1: defina a sua semana “tipo”

Faça um mini-retrato da sua realidade:

- Quantos dias por semana você se desloca?
- Em quais dias o trânsito/horários apertam mais?
- Há dias em que pode **evitar portagens** ou **estacionamento pago**?
- Você precisa de flexibilidade (ex.: deixas, reuniões, turnos)?

A sua semana “tipo” é o seu ponto de partida — não uma sentença.

## Passo 2: escolha 2–4 opções reais para comparar

Escolha alternativas que você **de facto** consegue executar. Exemplos:

- **Opção A:** sempre pela rota com portagens + estacionamento pago perto
- **Opção B:** rota sem portagens (ou com menos) + estacionamento mais barato/mais longe
- **Opção C:** portagens só em dias críticos + estacionamento com regra (ex.: 2 dias perto, 3 dias mais longe)
- **Opção D:** estacionamento alternativo (rua, parque mais afastado, partilha de boleia em alguns dias)

O objetivo é comparar **opções concretas**, não ideais.

## Passo 3: use a folha de pontuação (pesos 1–5, notas 1–5)

### Folha de pontuação em branco (preencha)

Escolha critérios, defina **peso** (importância) e dê **nota** (como cada opção se sai).  
Pesos: 1 (pouco importante) a 5 (muito importante).  
Notas: 1 (fraco) a 5 (excelente).

| Critério (exemplos) | Peso (1–5) | Opção A Nota (1–5) | Opção B Nota (1–5) | Opção C Nota (1–5) | Opção D Nota (1–5) |
|---|---:|---:|---:|---:|---:|
| Tempo total de deslocação |  |  |  |  |  |
| Previsibilidade (sem surpresas) |  |  |  |  |  |
| Flexibilidade (dias imprevistos) |  |  |  |  |  |
| Stress/energia mental |  |  |  |  |  |
| Risco (multas, atrasos, falhas) |  |  |  |  |  |
| Ajuste aos seus valores |  |  |  |  |  |
| Aprendizagem/controlo (fácil de seguir) |  |  |  |  |  |

**Como calcular:** para cada critério, faça `Peso x Nota` e some por opção. A melhor pontuação não “ganha a vida toda” — apenas indica **melhor ajuste agora**.

## Passo 4: transforme a opção vencedora num teto semanal simples

Depois de escolher a opção mais ajustada, converta em regra semanal que você consiga cumprir.

### Um método simples (sem complicar)

1. **Escolha o teto semanal**: um número que pareça “firme mas possível”.  
2. **Divida por blocos**, se ajudar:  
   - “dias críticos” (quando tempo importa mais)  
   - “dias flexíveis” (quando poupar é mais viável)  
3. **Defina 1–2 regras de decisão**, por exemplo:  
   - “Uso portagens apenas quando atraso > X minutos”  
   - “Estaciono perto no máximo 2 dias/semana”  

O teto semanal serve para orientar escolhas sem se vigiar a cada minuto.

## Passo 5: faça um “teste de stress” (troque dois pesos)

Aqui está o truque que evita arrependimentos: **troque dois pesos importantes** e veja se a decisão muda.

Exemplo:
- Se você deu **Peso 5** para “Tempo” e **Peso 3** para “Stress”, troque:
  - “Tempo” passa a 3
  - “Stress” passa a 5

Pergunta-chave: **a opção vencedora muda?**  
- Se **não mudar**, você tem uma decisão robusta.  
- Se **mudar**, você acabou de descobrir o verdadeiro dilema: tempo vs. stress (ou flexibilidade vs. risco). Isso é ótimo — agora você pode decidir conscientemente.

## Ajustes práticos para manter o teto sem se sentir preso

- **Crie uma margem de imprevistos** dentro do teto (uma parte “para dias difíceis”).  
- **Evite regras impossíveis** (“nunca mais uso portagens” raramente funciona).  
- **Planeie a exceção**: escolha antecipadamente quando vale “quebrar” a regra (e por quê).  
- **Reveja semanalmente** em 5 minutos: o que funcionou, o que foi pesado, o que ajustar.

Uma decisão “feita” e ajustável costuma bater uma decisão “perfeita” que nunca sai do papel.

## Como decidir entre poupar e ganhar tempo (sem culpa)

Quando a cabeça entra em espiral, volte ao básico:

- Se esta fase da vida está sobrecarregada, **reduzir stress** pode ser o critério nº1.
- Se o orçamento está apertado, **previsibilidade** e **controlo** podem valer mais que velocidade.
- Se você está a aprender um novo hábito, escolha a opção **mais fácil de executar** por 2–4 semanas.

O “melhor” é o que você consegue manter.

## Linguagem de compromisso (e um plano para reduzir risco)

Escolha uma frase de compromisso, simples e concreta:

- “Durante as próximas 3 semanas, vou seguir a Opção ___ com um teto semanal definido.”
- “Vou medir o que acontece na prática e ajustar, em vez de adivinhar.”

### Mini plano de “de-risk” (se a escolha estiver errada)

Se, na prática, a escolha não funcionar:
- **Sinal de alerta:** (ex.: atrasos frequentes, stress alto, sensação de perda de controlo)
- **Ajuste pequeno:** (ex.: acrescentar 1 dia de portagens, mudar 1 dia de estacionamento)
- **Nova revisão:** ao fim de 7 dias, com a mesma folha de pontuação

Assim, você não “falha” — você calibra.

## Common questions

### E se eu tiver semanas muito diferentes?
Use dois tetos: uma **semana normal** e uma **semana pesada**. O teto não precisa ser igual sempre — precisa ser previsível.

### Como não me perder no registo?
Mantenha o mínimo: anote só o total semanal (ou por dia crítico vs. flexível). Se registar for pesado, o sistema morre.

### E se eu estiver sempre a ultrapassar o teto?
Isso costuma indicar uma destas três coisas: o teto está baixo demais, as regras estão rígidas demais, ou a opção escolhida não encaixa na sua realidade. Volte ao score sheet, ajuste 1–2 pesos e reescolha.

### Quanto tempo devo testar antes de mudar?
Em geral, 2–4 semanas dão dados suficientes para sentir o impacto no tempo, no stress e na consistência — sem prolongar sofrimento.

## Fecho: escolha o que encaixa agora

Definir um teto semanal para estacionamento e portagens não é sobre controlo perfeito — é sobre **decidir com calma**, com critérios claros, e depois **viver a decisão** tempo suficiente para aprender. Hoje, escolha o melhor ajuste. Na próxima revisão, ajuste com gentileza e pragmatismo.
