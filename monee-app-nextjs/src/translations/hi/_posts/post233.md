कभी-कभी समस्या “कितना देना चाहिए?” नहीं होती—समस्या यह होती है कि हर बार **उसी सवाल पर फिर से सोचना** पड़ता है। यह पोस्ट आपको तय करने में मदद करती है कि **साल भर के जन्मदिन/छोटे मौकों के लिए एक सालाना गिफ्ट फंड** कैसे सेट करें, ताकि आप **कम तनाव** में, **ज्यादा स्पष्टता** के साथ निर्णय ले सकें।

## 3-प्रॉम्प्ट वैल्यूज़ वॉर्म-अप (30 सेकंड)

1) इस साल मैं गिफ्टिंग में क्या प्राथमिकता चाहती/चाहता हूँ: **रिश्ते, सादगी, या उदारता**?  
2) मेरे लिए “ठीक-ठाक” गिफ्ट का मतलब क्या है: **सोच-समझ, उपयोगिता, या अनुभव**?  
3) मैं किस चीज़ से बचना चाहती/चाहता हूँ: **आख़िरी समय की घबराहट, कर्ज़, या तुलना**?

बस इतने से आपके बजट की दिशा साफ़ होने लगती है।

## दो असली विकल्प (जिनमें से ज़्यादातर लोग चुनते हैं)

### विकल्प A: “एक निश्चित सालाना फंड”
आप पहले से तय कर लेते हैं कि साल भर में कुल कितना रखना है। फिर हर गिफ्ट उसी फंड से जाता है।

**कब अच्छा लगता है:** आपको स्पष्ट सीमा चाहिए, महीने-महीने ट्रैकिंग आसान चाहिए, और “अचानक खर्च” से बचना है।

### विकल्प B: “प्रति व्यक्ति/प्रति इवेंट कैप”
आप पहले से तय कर लेते हैं: करीबी लोगों के लिए अलग कैप, सामान्य रिश्तों के लिए अलग कैप, और बहुत छोटे मौकों के लिए मिनी-कैप।

**कब अच्छा लगता है:** आपकी सूची बड़ी/बदलती रहती है, आप लचीलेपन को प्राथमिकता देते हैं, और “हर रिश्ते का अलग मानक” रखना चाहते हैं।

## आपका ब्लैंक स्कोर शीट (Weights 1–5, Scores 1–5)

नीचे एक खाली स्कोर शीट है। आप अपने हिसाब से मानदंड बदल सकते हैं, पर इसे सरल रखें।

| मानदंड (Criteria) | Weight (1–5) | विकल्प A स्कोर (1–5) | विकल्प B स्कोर (1–5) |
|---|---:|---:|---:|
| समय/सरलता (कम सोच) |  |  |  |
| लचीलापन (लिस्ट बदलने पर) |  |  |  |
| तनाव (आख़िरी समय) |  |  |  |
| रिश्तों से मेल (values-fit) |  |  |  |
| जोखिम (ओवरस्पेंड/अपराधबोध) |  |  |  |
| सीख/सुधार (अगले साल बेहतर) |  |  |  |

**कैसे भरें:**  
- Weight: यह मानदंड आपके लिए कितना महत्वपूर्ण है (1 = कम, 5 = बहुत)।  
- Score: हर विकल्प इस मानदंड पर कैसा काम करेगा (1 = खराब, 5 = बहुत अच्छा)।  
- फिर (Weight × Score) जोड़कर कुल देखें।  

## एक उदाहरण (ताकि स्कोरिंग समझ आए)

मान लीजिए आपके लिए सबसे बड़ा दर्द “बार-बार सोचने का समय” और “तनाव” है। तब कई लोगों के लिए विकल्प A बेहतर स्कोर करेगा। अगर आपकी लिस्ट बहुत बदलती है (ऑफिस, दोस्तों के ग्रुप, रिश्तेदार), तो विकल्प B अक्सर आगे निकलता है।

यहाँ लक्ष्य “सही” ढूँढना नहीं—लक्ष्य **आपके जीवन के हिसाब से फिट** ढूँढना है।

## एक छोटा, व्यावहारिक नियम (बिना पैसे-नंबर के)

अगर आप अटक रहे हैं, तो यह फ्रेम इस्तेमाल करें:

- **विकल्प A** चुनें अगर आप चाहती/चाहता है कि “एक सीमा तय हो जाए और बस।”  
- **विकल्प B** चुनें अगर आप चाहती/चाहता है कि “हर तरह के रिश्ते के लिए अलग, पर सरल नियम हो।”

आप चाहें तो हाइब्रिड भी कर सकते हैं:  
- **एक सालाना फंड** (A) + **कुछ कैटेगरी कैप** (B) ताकि करीबी लोगों पर आप जानबूझकर अधिक प्राथमिकता दे सकें।

## अपनी पसंद को “Stress-test” करें (2 मिनट)

अब मज़ेदार हिस्सा: आप देखती/देखते हैं कि आपका निर्णय कितना स्थिर है।

1) अपनी शीट में सबसे ऊँचे दो weights पहचानें।  
2) उन दोनों weights को आपस में **swap** कर दें।  
3) फिर देखें: कुल स्कोर में जीतने वाला विकल्प बदलता है या नहीं?

- अगर **नहीं बदलता**, आपका निर्णय मजबूत है—आप बस पुष्टि चाह रहे थे।  
- अगर **बदल जाता**, तो संकेत है कि आपकी असल प्राथमिकता अभी साफ़ नहीं है। तब वॉर्म-अप के 3 प्रॉम्प्ट पर लौटें और एक weight को ईमानदारी से तय करें।

## निर्णय को “Done” बनाने के लिए 3 छोटे नियम

### 1) एक “डिफ़ॉल्ट” रखें
गिफ्टिंग में डिफ़ॉल्ट का मतलब है: कम निर्णय-थकान।  
- A में डिफ़ॉल्ट: “जो भी आएगा, फंड से जाएगा।”  
- B में डिफ़ॉल्ट: “कैटेगरी के हिसाब से कैप।”

### 2) एक छोटा बफ़र जोड़ें
जीवन में चीज़ें बदलती हैं। बफ़र आपको अपराधबोध से बचाता है और योजना को वास्तविक बनाता है।

### 3) साल के बीच में एक मिनी-रीसेट
एक छोटा चेक-इन: क्या यह सिस्टम तनाव घटा रहा है या बढ़ा रहा है? “फिट” बदल सकता है—और यह सामान्य है।

## Common questions

### अगर मेरा बजट साल के बीच में खत्म हो जाए तो?
यह failure नहीं है—यह डेटा है। आप या तो कैप थोड़ा कम करते हैं, या “मिनी-गिफ्ट/कार्ड/मैसेज” को डिफ़ॉल्ट बनाते हैं, या अगले साल weights में “जोखिम” और “तनाव” को बढ़ाते हैं।

### अगर मुझे लगता है लोग जज करेंगे?
ज्यादातर लोग आपकी राशि नहीं, आपकी **नियत और निरंतरता** महसूस करते हैं। और अगर कोई तुलना करे भी, तो आपका सिस्टम आपको “तुरंत रिएक्ट” करने से बचाता है।

### क्या मैं सालाना फंड और कैप दोनों रख सकती/सकता हूँ?
हाँ। अगर आपके रिश्तों की विविधता ज्यादा है, तो हाइब्रिड अक्सर सबसे सहज लगता है।

## कमिटमेंट + डी-रिस्क प्लान (शांत, व्यावहारिक)

मैं अगले 12 महीनों के लिए **एक ही सिस्टम चुन रही/रहा हूँ**—पर यह पत्थर की लकीर नहीं। अगर यह विकल्प गलत निकला, तो मैं:

- 30 दिन बाद शीट में weights दोबारा देखूँगी/देखूँगा  
- सिर्फ **एक नियम** बदलूँगी/बदलूँगा (पूरा सिस्टम नहीं)  
- और अगले महीने से वही अपडेट लागू करूँगी/करूँगा

फिट पर टिकना—पर जरूरत पड़ने पर छोटे, समझदार बदलाव करना—यही एक “done” निर्णय की पहचान है।
